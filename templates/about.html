About StudyBuddy

Purpose and scope

StudyBuddy is a machine learning project: a chatbot for BSCS (Bachelor of Science in Computer Science) students. It finds the closest prepared answer in a local CSV file and currently knows {{ size }} questions. It answers BSCS course questions only; anything else, and BSCS topics that are not yet in the dataset, get a polite "not found" reply with suggestions.

How the machine learning part works

  1. The questions in data/study_faq.csv are cleaned and normalised (lowercase, punctuation and filler words removed).
  2. Abbreviations such as ML or NLP are expanded using data/synonyms.csv.
  3. A TF-IDF vectorizer turns every stored question into numbers. Rare, informative words get more weight than common ones. A second view built from short character sequences helps when word endings differ (tokenizing / tokenization), and a third view also searches the stored answer text.
  4. Your question is converted the same way.
  5. Cosine similarity measures how close your question is to each stored one. The score is reduced when some of your words are unknown to the knowledge base.
  6. If the best score is at least {{ threshold }}, its answer is shown. Otherwise StudyBuddy says it could not find a match.

The similarity score is not a probability and not an accuracy figure. It only reflects word overlap, so a correct answer can be missed when you use very different words, and a wrong answer can occasionally be returned. Answers with a lower score are marked as the closest match found, and related questions are suggested.

Answer quality and your privacy

Answers reviewed by an instructor: {{ reviewed }} of {{ size }}. The answers were written for this project; treat unreviewed ones with care and check important facts against your textbook.

Your questions are processed locally and are not stored. They are saved to a local file only if you click Helpful or Not helpful{% if log_declined %}, and, because this copy has logging switched on, questions the bot cannot answer are also saved (text only, no personal data){% endif %}. The file is used to decide what to add next.{% if sync_warning %} Note: this copy stores it in a cloud-synced folder, so it may be uploaded to that cloud service.{% else %} It stays on this computer.{% endif %}

Optional intent classifier

The project also includes a separate experiment: a supervised classifier (TF-IDF + logistic regression) that predicts the topic of a question. Classification predicts a category; retrieval finds a prepared answer. The chat page uses retrieval only.

Technologies

Python, Flask, Pandas, scikit-learn, Joblib, HTML, CSS and JavaScript. No external AI APIs or keys.

Limitations

  • StudyBuddy only answers what is in its dataset. It does not understand language like a generative model.
  • The starter dataset is small and should be reviewed by a teacher before being relied on.
  • The quiz page shows stored questions and answers as flashcards; it records nothing.
